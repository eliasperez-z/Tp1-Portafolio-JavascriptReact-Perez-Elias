## Descripción del Proyecto
Este es un portafolio personal de una sola pagina desarrollado como Trabajo Practico Nº 1 para la UTN. El proyecto divide la interfaz en componentes reutilizables y demuestra conceptos fundamentales de React como el uso de props, renderizado dinamico con arrays, renderizado condicional y manejo de estado.

## Tecnologías Utilizadas
- React
- Vite
- JavaScript (JSX)
- CSS

## Instrucciones de Instalación
Para preparar este proyecto en un entorno local, abre una terminal en la carpeta del proyecto y ejecuta el siguiente comando para instalar las dependencias:
```bash

npm install
```
## Ejecución del Proyecto
Para levantar el servidor y ver la página funcionando, ejecuta:
```bash
npm run dev
```
