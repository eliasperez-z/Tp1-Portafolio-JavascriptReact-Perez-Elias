## Descripción del Proyecto
Este es un portafolio personal de una sola pagina desarrollado como Trabajo Practico Nº 1 para la UTN. El proyecto divide la interfaz en componentes reutilizables y demuestra conceptos fundamentales de React como el uso de props, renderizado dinamico con arrays, renderizado condicional y manejo de estado.

## Tecnologías Utilizadas
- React
- Vite
- JavaScript (JSX)
- CSS
