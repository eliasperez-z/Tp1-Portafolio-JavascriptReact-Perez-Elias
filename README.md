## Descripción del Proyecto
Este es un Este proyecto es la continuación del TP1 (Trabajo Práctico Nº 2) para la UTN. Transformé mi portfolio personal de una sola página en una aplicación multipágina interactiva. Implementé la navegación entre distintas secciones utilizando React Router Dom sin necesidad de recargar la página, organizando el código en páginas (pages) y componentes reutilizables (components).

## Tecnologías Utilizadas
- React
- Vite
- JavaScript (JSX)
- CSS
- React Router Dom

## Instrucciones de Instalación
Para preparar este proyecto en un entorno local, abre una terminal en la carpeta del proyecto y ejecuta el siguiente comando para instalar las dependencias:
```bash

npm install
```
## Ejecución del Proyecto
Para levantar el servidor y ver la página funcionando, ejecuta:
```bash
npm run dev
```
